Python Banking Program

A simple console-based banking program built with Python. This project was created to practice Python fundamentals such as functions, loops, conditionals, user input, parameters, and return values.

Features
💰 Show current balance
➕ Deposit money
➖ Withdraw money
🚫 Check for insufficient funds
✅ Validate deposit and withdrawal amounts
🚪 Exit the program
Python Concepts Used
Functions
Parameters and arguments
Return values
while loops
if / elif / else statements
User input with input()
Type conversion using float()
f-strings
Basic input validation
How to Run

Make sure Python is installed on your computer.

Run the program from the terminal:

python banking.py
